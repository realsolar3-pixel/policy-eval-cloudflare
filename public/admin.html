평가표 접속

위원 이름(실명)과 회차별 공통 비밀번호를 입력해 주세요.

상품 관리

상품을 선택하면 3·4단계 평가 설정을 수정할 수 있습니다.

상품 추가

선택한 평가표의 정성평가 항목과 배점이 자동 적용됩니다. 3단계는 공통 템플릿입니다.

안건별 평가위원 지정

제안자는 해당 안건의 평가와 의결정족수에서 제외됩니다. 아래 체크된 위원만 평가표가 표시됩니다.

평가표 템플릿 관리

정성평가 항목과 배점만 관리합니다. 정량점수는 상품별로 입력합니다. 기존 상품의 평가표는 템플릿을 수정해도 변경되지 않습니다.

평가위원 명단

등록된 평가위원별 평가 완료 건수를 확인할 수 있습니다.

회차별 공통 비밀번호

평가위원은 이름과 해당 회차 공통 비밀번호로 로그인합니다. 비밀번호는 6자 이상으로 설정해 주세요. 비밀번호 변경 시 해당 회차의 기존 로그인은 해제됩니다.
